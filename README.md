# 🌍 Vayu Bhraman – Explore, Travel & Discover

**Vayu Bhraman** is a tourism and travel management web application designed to help users explore tourist destinations, plan their journeys, discover events, and access emergency assistance.

The platform aims to make travelling easier, more convenient, and more accessible by bringing essential travel-related services together in one place.

## 🚀 Features

- **User Authentication:** Secure user registration and login functionality.
- **Explore Destinations:** Discover different tourist destinations and explore new places.
- **Travel Planning:** Plan trips and organize travel-related information.
- **Events:** Explore travel-related events and activities.
- **Emergency Assistance:** Access an emergency assistance section for support during travel.
- **User-Friendly Interface:** Simple, responsive, and easy-to-navigate design.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Vayu-Bhraman
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

For Windows:

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install django
```

**6. Apply database migrations**

```bash
python manage.py migrate
```

**7. Run the development server**

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
